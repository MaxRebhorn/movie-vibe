| Rolle                    | Beschreibung                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| **Anonymer Nutzer**      | Kann nach Filmen suchen, sich Stimmungen anzeigen lassen, aber keine Bewertungen abgeben. |
| **Registrierter Nutzer** | Kann eigene Filme taggen, beschreiben, bewerten und Ähnlichkeiten vergleichen.            |
| **Admin**                | Kann Benutzer sperren, problematische Inhalte moderieren und System-Statistiken einsehen. |
